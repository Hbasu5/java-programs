# Palprime Number



---



# What is a Palprime Number?



A Palprime number is a number that is both:



* A Palindrome (same forward and backward)

* A Prime number (only divisible by 1 and itself)



Examples



`101` → Palprime



`121` → Not Palprime



---



# Logic Steps:

- Input: Takes starting and ending range from user

- Swaps values if input is reversed

- Iterates through each number in the range

- Checks: If number is prime then If number is palindrome

- Prints numbers satisfying both conditions

- Asks user whether to continue
